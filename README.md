# Explore! Geography games

Map games for primary school children, with Junior (Infants–2nd) and Senior (3rd–6th) levels.

- `ireland/` — Explore Ireland: counties, provinces, landmarks, lighthouses, towns, rivers and mountains, GAA, Cúpla Focal and Wild Ireland.
- `europe/` — Explore Europe: countries, capitals, flags and landmarks.

Each game is a single self-contained HTML file with no outside links, so it works offline. To publish with GitHub Pages: Settings → Pages → deploy from the `main` branch, root folder.

Map data: Natural Earth (public domain). Flags: flag-icons (MIT). Photos: Unsplash and Wikimedia Commons (credits listed in each game's help screen).
